# RCA — Redeploy failed at build_image (Cloud Build queue timeout)

## Deployment
- Deployment: depann-24h (3ff62736-bad0-4eba-b057-247e91943438)
- Template: fastapi_react_mongo_shadcn_base_image, arch arm64, tier_0, frontend cloudflare
- Live URL (unchanged, still serving previous good version): https://depann-24h.emergent.host

## Symptom
Redeploy fails at the `build_image` step. Two separate run attempts both failed identically:
- run fe49db58-aa6d-4e82-986e-91ec726ca8e7 (original trigger)
- run 6c3f9ad3-5566-4533-a40d-cb125c965fd8 (my force_repull retry)

Both ended with:
`build ... ended in FAILED (last phase context: QUEUED/Build has timed out in the queued phase)` (TerminalCloudBuildFailure).

## Root Cause
Cloud Build never left the **QUEUED** phase — the build was waiting for a build worker and timed out before any build step ran. Evidence:
- The failure phase context is literally `QUEUED/Build has timed out in the queued phase`.
- `get_build_logs` returned `build_logs_unavailable` — no build output exists because no build step ever executed.
- The 4 most recent prior runs on this exact template/arch/tier all built successfully, so the Dockerfile/manifests and source compile fine.

This is a **platform-side Cloud Build capacity / scheduling issue** (the build pool, likely the arm64 builder capacity in the region, did not pick up the job within the queue timeout). It is NOT a source, dependency, or manifest fault.

## What I tried
- Oriented with describe_deployment_state (confirmed prior runs green on same template).
- Attempted to read build logs — none available (build never ran).
- Re-fired the pipeline with resume_pipeline(force_repull=true) — same queued-phase timeout.

## Fix / Next steps
- No manifest or code change is applicable; a build that never leaves the queue cannot be fixed by editing files.
- This needs the Emergent platform team to check Cloud Build builder-pool capacity / queue health for arm64 in the target region. Once builder capacity is restored, a plain redeploy should succeed unchanged.
